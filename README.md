# UI/UX Designer Portfolio

A professional, minimal, and modern portfolio website showcasing digital product design, brand identity, and UI/UX case studies. Built with a focus on clean aesthetics, responsive design, and smooth user experiences.

## 🎨 Design Philosophy & Workflow

The design process for this portfolio (and the projects within) follows a user-centered approach:

1. **Research & Discovery**: Understanding the target audience and establishing the core message.
2. **Wireframing (Figma)**: Creating low-fidelity layouts to define structure and content hierarchy.
3. **High-Fidelity Prototyping**: Developing polished UIs with a strict design system (deep charcoal, electric blue, soft grey).
4. **Implementation**: Translating the design into a lightweight, performant web experience.

## ✨ Features

- **Minimalist Aesthetics**: Ample whitespace and high-contrast typography (using the `Outfit` font family).
- **Responsive Layout**: Fluid CSS Grid and Flexbox implementation ensuring perfect rendering across mobile, tablet, and desktop devices.
- **Micro-Animations**: Scroll-triggered fade-ins and interactive hover states using Intersection Observer.
- **Premium Showcase**: High-quality galleries for mobile app interfaces and branding case studies.

## 🛠️ Built With

- **HTML5**: Semantic and accessible structure.
- **CSS3 (Vanilla)**: Custom design system utilizing CSS Variables without the bloat of external frameworks.
- **JavaScript (Vanilla)**: Lightweight interactivity, mobile navigation, and scroll animations.
- **Figma / Adobe Creative Suite**: For all UI prototypes, graphic assets, and brand identities showcased.

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge).
- Optional: A local development server like VS Code's "Live Server" extension for a better development experience.

### Local Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/your-repo-name.git
   ```
2. Navigate to the project directory:
   ```bash
   cd your-repo-name
   ```
3. Open `index.html` directly in your browser, or start your local server.
